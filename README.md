# Админка сайтов

[Публичное демо](https://irinakratyuk.github.io/sites-admin/)

Стартовый экран из [Figma, 40:27302](https://www.figma.com/design/yyFV4fgzdkidWzcmCzHbRa/?node-id=40-27302). Сцена 1600×900 масштабируется под окно браузера.

Данные перенесены из макета: 21 строка и 24 региона. Поиск работает по названию, адресу, организации и ИНН; строки выбираются кликом. У демонстрационных записей адреса Адыгеи, поэтому остальные регионы не содержат строк. Переходы к другим экранам не добавлены.

Без сборки и зависимостей. Для локального просмотра: `python3 -m http.server 5173`.

Шрифты Inter, cbuc-icons и cbuc-icons24 переиспользуются из IrinaKratyuk/popups, зафиксированного коммита d935e6a587f1c557820149fdd7066879f3628df6. SVG берутся из указанного узла Figma. Скрипт ресурсов использует curl и сохраняет их локально; временные адреса Figma не используются приложением.

Правила проекта и исправленные ошибки хранятся в AGENTS.md.


Карточка открывается кликом по записи и закрывается крестиком или Esc. Реализованы вкладки «Страницы» и «Параметры», выбор страницы и переключение размера превью. Прочие вкладки оставлены без переходов: их состояния не заданы. Все карточки используют демонстрационное наполнение биллингового сайта из Figma; название соответствует выбранной записи.

Фильтр: шаблон, организация, проверка и публикация. Зелёная кнопка применяет изменения, «Сбросить» очищает фильтр. Множественный выбор включается кнопкой справа или чекбоксом записи; доступны выбор всех видимых и изменение демонстрационного статуса публикации. Данные сбрасываются при перезагрузке.
